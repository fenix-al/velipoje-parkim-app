# PWA Icons

Place the following icon files here:

- `icon-192.png` — 192×192 px, used for Android home screen and manifest
- `icon-512.png` — 512×512 px, used for splash screen and manifest
- `apple-touch-icon.png` — 180×180 px, used for iOS home screen

These can be generated from a single SVG source using tools like:
- https://maskable.app/editor
- `sharp` npm package
- Imagemagick

The icon should use the parking symbol (P) with a blue background (#1d4ed8).
